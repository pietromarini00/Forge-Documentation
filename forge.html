Retrieval Engines

[claude-assisted] TF-IDF based text similarity.

Provides lexical matching via TF-IDF vectorization and cosine similarity.

class forge_retrieval_core.tfidf_engine.TFIDFEngine(config: RetrievalConfig | None = None)

TF-IDF based text similarity engine.

Used for lexical (token-level) matching. Catches variations like PatientAge vs patient_age through normalization.

fit(texts: List[str], background_texts: List[str] | None = None) → None

Build vocabulary and TF-IDF matrix from texts.

When background_texts is provided it takes precedence; otherwise the corpus source is resolved from config (wordnet / file / none). The vectorizer is fitted on background_texts + texts for IDF calibration, but only the transforms of texts are stored in self.matrix.

Args:

texts: List of texts to index (element texts). background_texts: Optional explicit background corpus; overrides config when provided.

load(path: str) → bool

Load fitted vectorizer and matrix from disk.

Args:

path: Directory path for loading

Returns:

True if loaded successfully, False otherwise

static load_bundled_corpus(filename: str) → List[str]

Load a bundled background corpus from the package data directory.

Args:

filename: Name of the .csv.gz file inside forge_retrieval_core/data/.

Returns:

List of normalized text strings.

static load_wordnet_corpus() → List[str]

Load English word definitions from WordNet for IDF calibration.

Each WordNet synset contributes a normalized text of the form “word definition [example …]”. With ~117k synsets this corpus is large enough to meaningfully suppress common English terms and boost rare domain-specific tokens in subsequent IDF scoring.

Requires the ‘nltk’ package and the ‘wordnet’ corpus data. Install with: pip install nltk && python -m nltk.downloader wordnet

Returns:

List of normalized text strings, one per WordNet synset.

Raises:

ImportError: If nltk is not installed. LookupError: If the WordNet corpus data has not been downloaded.

pairwise_similarity(text_a: str, text_b: str) → float

Compute TF-IDF similarity between two texts.

This creates a temporary vectorizer for the pair. For bulk comparisons, use similarity_matrix() instead.

Args:

text_a: First text text_b: Second text

Returns:

Cosine similarity score between the texts

Returns:

ValueError: If engine has not been fitted

[claude-assisted] Score combination for hybrid retrieval.

Combines TF-IDF and embedding scores using weighted average or RRF.

class forge_retrieval_core.score_combiner.ScoreCombiner(config: RetrievalConfig | None = None)

Combines TF-IDF and embedding scores.

Supports weighted average and Reciprocal Rank Fusion (RRF) modes.

combine(tfidf_scores: ndarray[tuple[Any, ...], dtype[float64]], embedding_scores: ndarray[tuple[Any, ...], dtype[float64]], tfidf_weight: float | None = None, embedding_weight: float | None = None) → ndarray[tuple[Any, ...], dtype[float64]]

Combine score arrays using weighted average.

Args:

tfidf_scores: Array of TF-IDF scores embedding_scores: Array of embedding scores tfidf_weight: Override TF-IDF weight (default from config) embedding_weight: Override embedding weight (default from config)

Returns:

Combined score array

combine_matrices(tfidf_matrix: ndarray[tuple[Any, ...], dtype[float64]], embedding_matrix: ndarray[tuple[Any, ...], dtype[float64]], tfidf_weight: float | None = None, embedding_weight: float | None = None) → ndarray[tuple[Any, ...], dtype[float64]]

Combine pairwise similarity matrices.

Args:

tfidf_matrix: N×N TF-IDF similarity matrix embedding_matrix: N×N embedding similarity matrix tfidf_weight: Override TF-IDF weight (default from config) embedding_weight: Override embedding weight (default from config)

Returns:

Combined N×N similarity matrix

combine_scores(tfidf_score: float, embedding_score: float, tfidf_weight: float | None = None, embedding_weight: float | None = None) → float

Combine individual scores.

Args:

tfidf_score: TF-IDF similarity score embedding_score: Embedding similarity score tfidf_weight: Override TF-IDF weight (default from config) embedding_weight: Override embedding weight (default from config)

Returns:

Combined score

combine_with_rrf(tfidf_scores: ndarray[tuple[Any, ...], dtype[float64]], embedding_scores: ndarray[tuple[Any, ...], dtype[float64]], k: int = 60) → ndarray[tuple[Any, ...], dtype[float64]]

Combine TF-IDF and embedding scores using RRF.

Args:

tfidf_scores: Array of TF-IDF scores embedding_scores: Array of embedding scores k: RRF constant

Returns:

Combined RRF scores

reciprocal_rank_fusion(score_arrays: List[ndarray[tuple[Any, ...], dtype[float64]]], k: int = 60) → ndarray[tuple[Any, ...], dtype[float64]]

Combine multiple score arrays using Reciprocal Rank Fusion.

RRF(d) = sum(1 / (k + rank(d))) for each ranking

This method is more robust when the two rankings strongly disagree, as it avoids averaging scores on different scales.

Args:

score_arrays: List of score arrays to combine k: RRF constant (default 60, recommended in original paper)

Returns:

Combined RRF scores
