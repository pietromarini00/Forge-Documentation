Local Development Setup

Prerequisites

  • Python 3.11+

  • Docker and Docker Compose

  • An Anthropic API key (for AI features in forge-app)

Quick Start (Docker — all services)

# Clone and enter the repo
git clone <repo-url> && cd cde-engine

# Set up environment
cp .env.example .env
# Edit .env and add your ANTHROPIC_API_KEY

# Start everything
docker compose up --build

Services come up at:

Service

URL

What to check

forge-app

http://localhost:8505

Main UI — should show home dashboard

Registry Service

http://localhost:8000/health

Should return {"status": "healthy"}

DataForge API

http://localhost:8001/health

Should return {"status": "healthy"}

PostgreSQL

localhost:5432

User: forge, password: forge, db: forge

The legacy standalone services (:8501, :8502, :8503) also start but aren’t needed for development.

To start only what you need:

docker compose up --build forge-app registry-service dataforge-api postgres

Local Python Setup (for running tests and linting)

Tests run against the local Python environment, not Docker.

1. Create a virtualenv from the repo root

python3.11 -m venv .venv
source .venv/bin/activate

2. Install each service you’re working on

forge-app:

pip install -r services/forge-app/requirements.txt
pip install -e libs/forge-retrieval-core

Registry Service:

pip install -r services/registry-service/requirements.txt

DataForge:

pip install -e "services/dataforge[dev]"

forge-retrieval-core (standalone):

pip install -e "libs/forge-retrieval-core[dev]"

3. Run tests

Always run from the repo root using .venv/bin/python:

# forge-app
.venv/bin/python -m pytest services/forge-app/tests/ -x -q

# Registry Service (uses in-memory SQLite, not PostgreSQL)
.venv/bin/python -m pytest services/registry-service/tests/ -x -q

# DataForge
.venv/bin/python -m pytest services/dataforge/tests/ -x -q

# forge-retrieval-core
.venv/bin/python -m pytest libs/forge-retrieval-core/tests/ -x -q

4. Linting (optional, CI linting currently disabled)

black --check --line-length 100 .
flake8 --max-line-length=110 --extend-ignore=E203,W503

Common Issues

ModuleNotFoundError: shared.logging Set PYTHONPATH to include the services directories:

export PYTHONPATH=services/shared:services/:$PYTHONPATH

forge-retrieval-core not found by forge-app tests Install it as an editable package:

pip install -e libs/forge-retrieval-core

DataForge import errors DataForge is a package, not a plain script directory. Install it:

pip install -e "services/dataforge[dev]"

Registry tests fail with PostgreSQL errors Registry tests use in-memory SQLite by default (see services/registry-service/tests/conftest.py). They don’t need a running PostgreSQL instance.

Streamlit use_container_width deprecation warnings Use width="stretch" instead of use_container_width=True. This is a codebase convention.
